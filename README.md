# Asistente Virtual SOLUT

Proyecto hermano de [GEOSOM](https://github.com/Fmatamalaa/GEOSOM), para automatizar la captación y calificación de prospectos de **SOLUT** (la matriz de ingeniería geotécnica) y agendar su evaluación técnica.

## Objetivo

Igual que GEOSOM: un prospecto interactúa con el asistente, entrega datos de su proyecto, se filtra/califica, y si califica agenda directo una **evaluación técnica** con el equipo de SOLUT.

## Estructura

- `01_Documentacion_Tecnica/` — servicios y capacidades técnicas de SOLUT
- `02_Marketing/` — contenido de marketing (carrusel LinkedIn, etc.)
- `03_Flujo_Conversacional/` — guion del asistente, preguntas de calificación
- `04_Configuracion_Agenda/` — configuración de agenda virtual
- `05_Notas_Reuniones/`

## Relación con GEOSOM

GEOSOM es un producto/plataforma "by SOLUT" enfocado en geotermia. SOLUT es la matriz de ingeniería geotécnica (suelos, hormigón, minería, infraestructura, energía). Son públicos y guiones relacionados pero distintos — por eso van en repos separados.
